# Веб-приложение для визуализации обучения нейронных сетей

Проект представляет собой учебное React-приложение для исследования того, как на обучение нейронной сети влияют данные, архитектура, функция активации, оптимизатор, скорость обучения, регуляризация, инициализация весов и смещений. Обучение выполняется прямо в браузере через TensorFlow.js, поэтому серверная часть не обучает модель и не хранит результаты.

Приложение состоит из двух разделов:

- классификация: бинарная и многоклассовая классификация точек и пользовательских CSV-данных;
- регрессия: аппроксимация одномерных функций, диагностика ошибок и загрузка пользовательских CSV-данных.

## Технологии

- React 19 - интерфейс и состояние приложения.
- TensorFlow.js - создание, обучение и запуск моделей в браузере.
- Vite - dev-сервер и production-сборка.
- lucide-react - иконки интерфейса.
- PapaParse - основной CSV-парсер, если подключен через CDN; при его отсутствии используется встроенный fallback-парсер.

## Запуск

```bash
npm install
npm run dev
```

После запуска приложение доступно на адресе, который выводит Vite. Обычно это `http://localhost:5173/`.

Разделы открываются через переключатель в шапке приложения:

- `#classification` или пустой hash - классификация;
- `#regression` - регрессия.

## Сборка

```bash
npm run build
```

Готовые статические файлы создаются в папке `dist`. Их можно раздавать любым статическим сервером: Nginx, Express static, Spring static resources, ASP.NET static files или другим backend без дополнительной обработки параметров модели.

```bash
npm run preview
```

Команда запускает локальный preview production-сборки.

## Основные возможности

### Классификация

Раздел классификации предназначен для демонстрации бинарной классификации.

Возможности:

- генерация учебных датасетов;
- загрузка своего CSV-файла;
- настройка количества скрытых слоев и нейронов;
- выбор функции активации;
- выбор функции потерь;
- выбор оптимизатора;
- настройка learning rate, эпох и batch size;
- настройка регуляризации;
- настройка инициализации весов и смещений;
- включение и отключение смещений в Dense-слоях;
- критерий остановки обучения по accuracy;
- визуализация области решений;
- график ошибки по эпохам;
- график accuracy по эпохам;
- ручное предсказание класса и вероятностей по введенным признакам;
- просмотр численных весов и смещений в отдельном блоке;
- подсказки рядом с параметрами нейросети.

Граф архитектуры модели показывает только структуру сети: входы, скрытые слои, выход и связи между нейронами. Численные веса на нем не выводятся, чтобы схема оставалась читаемой. Для численного анализа параметров используется отдельный блок "Веса и смещения".

### Регрессия

Раздел регрессии предназначен для изучения аппроксимации непрерывной целевой переменной.

Встроенные датасеты:

- `Sine wave`: `y = sin(x) + noise`, диапазон `x` от `-3` до `3`;
- `Polynomial`: `y = x^3 - 2x^2 + x + noise`, диапазон `x` от `-2` до `2`;
- `Multi-modal`: `y = exp(-x^2) * sin(5x) + noise`, диапазон `x` от `-2` до `2`;
- `CSV`: пользовательский датасет с числовыми и категориальными признаками.

Возможности:

- слайдер шума от `0.0` до `0.3` для синтетических данных;
- StandardScaler для входных признаков `X`;
- опция `Scale Y` для нормализации целевой переменной;
- обратное преобразование предсказаний к исходной шкале `Y`;
- включение и отключение смещений в Dense-слоях;
- график train loss и validation loss;
- график Actual vs Predicted с диагональю идеального предсказания;
- residual plot с линией нулевой ошибки;
- блок ручного прогноза: можно ввести свои значения признаков, а для категориальных CSV-признаков выбрать категорию из списка;
- загрузка пользовательского CSV-файла;
- подсказки по параметрам обучения.

## CSV-датасеты

Все пользовательские CSV-файлы проходят общую базовую проверку:

- допускаются числовые и категориальные признаки;
- пустые ячейки запрещены;
- минимум 2 колонки и максимум 5 колонок вместе с целевой;
- от 10 до 500 строк данных включительно;
- заголовок определяется автоматически;
- если заголовка нет, имена колонок создаются автоматически: `column1`, `column2`, `column3` и так далее;
- после загрузки открывается окно настройки датасета: можно переименовать столбцы, выбрать целевую колонку, указать тип признаков и способ кодирования категорий.

### CSV для классификации

Для классификации пользователь сам выбирает колонку с меткой класса. Метки могут быть числовыми или текстовыми, поддерживается многоклассовая классификация. Независимые переменные могут быть непрерывными или категориальными.

Минимальный формат:

```csv
x1,x2,label
-0.7,0.3,0
0.8,-0.2,1
```

Если признаков больше двух, модель использует их при обучении, но визуализация области решений строится по первым двум признакам.

Пример находится в файле `public/datasets/example.csv`.

### CSV для регрессии

Для регрессии пользователь сам выбирает зависимую переменную. Целевая колонка должна быть числовой. Независимые переменные могут быть непрерывными или категориальными.

Минимальный формат:

```csv
x,y
-3.0,-0.19
-2.8,-0.29
```

Тестовый датасет для загрузки в раздел регрессии находится в файле `public/datasets/regression-example.csv`. Это небольшой числовой датасет с одной входной колонкой `x` и целевой колонкой `y`, похожий на зашумленную синусоиду.

## Назначение ключевых модулей

`src/main.jsx` подключает React-приложение к DOM.

`src/App.jsx` содержит общий каркас интерфейса, переключатель между классификацией и регрессией, шапку и основной layout.

`src/pages/RegressionPage.jsx` описывает страницу регрессии. Страница использует тот же визуальный стиль, что и основной раздел классификации.

`src/config/trainingConfig.js` хранит настройки и допустимые значения для классификации: функции активации, оптимизаторы, регуляризация, инициализаторы и лимиты параметров.

`src/config/regressionConfig.js` хранит настройки и допустимые значения для регрессии.

`src/core/CSVDataLoader.js` отвечает за загрузку, парсинг и базовую валидацию CSV. Модуль создает `input[type="file"]`, принимает только `.csv`, определяет заголовок, проверяет ограничения по строкам и столбцам, отсутствие пустых ячеек и возвращает строки CSV для последующей настройки.

`src/core/csvDatasetBuilder.js` применяет пользовательскую настройку CSV: выбирает целевую колонку, переименовывает столбцы, кодирует категориальные признаки через One-Hot или Label Encoding и готовит числовую матрицу признаков.

`src/core/customDataset.js` преобразует настроенный CSV в датасет классификации: нормализует признаки, кодирует классы, поддерживает бинарную и многоклассовую классификацию, перемешивает данные и делит их на train/test.

`src/core/datasets.js` генерирует встроенные датасеты для классификации.

`src/core/neuralNetworkEngine.js` создает и обучает TensorFlow.js-модель классификации, обновляет историю метрик, параметры модели и сетку решений.

`src/core/regressionDatasets.js` генерирует встроенные регрессионные датасеты и преобразует CSV в формат регрессии. Здесь выполняется StandardScaler для `X`, опциональное масштабирование `Y`, train/validation split и обратное преобразование целевых значений.

`src/core/regressionEngine.js` создает и обучает TensorFlow.js-модель регрессии, считает diagnostics для графиков Actual vs Predicted и Residual plot.

`src/hooks/useTrainingController.js` связывает интерфейс классификации с генерацией данных, валидацией, созданием модели и обучением.

`src/hooks/useRegressionController.js` выполняет такую же роль для регрессии: управляет настройками, датасетом, обучением, диагностикой и ручными предсказаниями.

`src/utils/validation.js` и `src/utils/regressionValidation.js` проверяют корректность пользовательских настроек перед созданием и обучением модели.

`src/components/` содержит переиспользуемые визуальные компоненты: панели настроек, графики, визуализацию датасетов, граф архитектуры, блок весов и смещений, статусы и подсказки.

`src/styles.css` содержит все стили интерфейса, включая layout, панели, графики, кнопки, формы и адаптивное поведение.

`public/datasets/` содержит CSV-файлы, которые можно использовать как примеры для загрузки.

`dist/` содержит production-сборку. Если проект передается вместе с уже собранным frontend, backend может отдавать именно эту папку.

## Поток данных

1. Пользователь выбирает раздел, датасет и параметры модели.
2. React-контроллер проверяет настройки через validation-модуль.
3. Для встроенных датасетов данные генерируются локально.
4. Для CSV-датасетов `CSVDataLoader` читает файл, парсит строки и выполняет базовую проверку структуры.
5. Пользователь настраивает столбцы в `CsvDatasetSetupModal`: выбирает target/label, типы признаков и способ кодирования категорий.
6. Dataset-модуль преобразует данные в train/test или train/validation выборки.
7. Engine-модуль создает TensorFlow.js-модель и запускает обучение.
8. Во время обучения callback обновляет историю метрик и состояние интерфейса.
9. После обучения обновляются графики, веса, смещения, диагностика и предсказания.

## Роль backend

Backend в текущей архитектуре нужен только для раздачи статических файлов. Он не обязан:

- принимать параметры модели;
- хранить CSV-файлы;
- обучать TensorFlow-модель;
- хранить веса;
- считать метрики.

Если в будущем потребуется серверное хранение экспериментов, backend можно расширить отдельными API для загрузки датасетов, сохранения конфигураций и истории обучения. Текущая версия проекта специально оставляет обучение в браузере, чтобы поведение модели было наглядным и легко воспроизводимым.
