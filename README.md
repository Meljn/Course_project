# Веб-приложение для визуализации обучения нейронной сети

Frontend реализован на React и TensorFlow.js. Обучение выполняется полностью в браузере, backend нужен только для раздачи статических файлов из сборки.

## Запуск frontend

```bash
npm install
npm run dev
```

## Сборка для статического backend

```bash
npm run build
```

Готовые файлы появятся в папке `dist`. Их можно отдавать любым статическим сервером: Nginx, Express static, Spring static resources, ASP.NET static files или другим backend без обработки параметров модели.

## Архитектура

- `src/core` содержит TensorFlow.js-ядро и генератор учебных данных.
- `src/hooks/useTrainingController.js` связывает интерфейс, валидацию и ядро обучения.
- `src/components` содержит визуальные компоненты без логики обучения.
- `public` предназначен для статических ресурсов, которые в будущем может отдавать backend.

Backend не создает модель, не обучает ее и не хранит результаты. Все параметры, веса, смещения и метрики остаются в состоянии frontend.
